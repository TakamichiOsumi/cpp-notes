# cpp-notes
My personal notes during self-study of C++ for competitive programming

### My rules for this repo

- Use DuckDuckGo whose settings for AI Features are all off.
  "Duck.ai" is Off, "Search Assist Settings" is Never and "Hide AI-Generated Images" is On.
- Type all information by myself, based on my understandings about algorithms.
  (Never copy and paste someone's codes !)
- Turn off all editor (emacs) settings and use it to create any contribution for this repository.
  I just allocate some minimum settings, following the official emacs document, as
  copied like "dot_emacs" in this repo.
- Needless to say, the fundamental core parts of C++ such as basic syntax (if, for, ...) and
  standard libraries are atomic and cannot be divied into smaller parts for solving
  competition problems quickly (in many cases). Therefore, using them are acceptable, when I can clarify
  the necessity of them.
- Solve problems first and update the repo's snippets after that, utilizing my submissions.
  This ensures that the entire source of the snippets comes from my own submission
  and does not depend on others' codes.

Those rules are OK and compatible with the latest AtCoder's "AtCoder生成AI対策ルール - 20261014版",
since following above my rules means I never use Generative AI and someone's source codes at all
for competition (and solving past competiton problems).
